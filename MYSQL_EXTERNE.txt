BRANCHER L'API DOCKER SUR TON MYSQL (visible dans phpMyAdmin)
================================================================
But : Docker n'utilise plus son propre MySQL, l'API ecrit dans TA base
(ex : Launcher) sur le MySQL installe sur le serveur. Le port API reste 3001.

A. CREER LA TABLE + L'USER MYSQL (via phpMyAdmin)
--------------------------------------------------
1. Dans phpMyAdmin, clique sur ta base (ex : Launcher) -> onglet SQL,
   colle le contenu de server/schema-externe.sql -> Executer.
   Verifie : la table users apparait dans la base.

2. Toujours dans phpMyAdmin (onglet SQL, sans selectionner de base),
   cree un user dedie a l'API (remplace MOT_DE_PASSE_FORT) :
     CREATE USER IF NOT EXISTS 'launcher_api'@'%' IDENTIFIED BY 'MOT_DE_PASSE_FORT';
     GRANT ALL PRIVILEGES ON Launcher.* TO 'launcher_api'@'%';
     FLUSH PRIVILEGES;
   (Si ta base s'appelle autrement, remplace Launcher par son nom.)

B. AUTORISER DOCKER A JOINDRE MYSQL (sur le Linux, en SSH)
---------------------------------------------------------
Le conteneur ne peut pas utiliser "localhost". Il passe par
host.docker.internal (= l'hote). Mais MySQL doit l'accepter :

1. Verifie sur quoi MySQL ecoute :
  sudo ss -tlnp | grep 3306
  grep -r bind-address /etc/mysql/ 2>/dev/null

  - Si bind-address = 127.0.0.1 : Docker sera REFUSE. Corrige :
    sudo nano /etc/mysql/mysql.conf.d/mysqld.cnf
    # mets : bind-address = 0.0.0.0
    sudo systemctl restart mysql
  - Si 0.0.0.0 : OK, passe a la suite.

2. Si ufw actif, autorise le reseau Docker vers MySQL :
  sudo ufw allow from 172.16.0.0/12 to any port 3306
  (ou au minimum : sudo ufw allow 3306/tcp)

C. CONFIGURER ET LANCER L'API
-----------------------------
  cd ~/LauncherMinecraft
  git pull
  cp .env.example .env
  nano .env
  # Remplis :
  #   DB_HOST=host.docker.internal  (ne pas changer)
  #   DB_PORT=3306
  #   DB_USER=launcher_api
  #   DB_PASSWORD=MOT_DE_PASSE_FORT  (celui de l'etape A.2)
  #   DB_NAME=Launcher               (nom exact de ta base phpMyAdmin)
  #   JWT_SECRET=<openssl rand -base64 48>

  docker compose up -d --build
  docker compose logs -f api
  # Attendu : [DB] MySQL connecte + table users OK  puis  [API] http://localhost:3001

D. VERIFIER QUE DOCKER ECRIT CHEZ TOI
-------------------------------------
  curl -X POST http://localhost:3001/api/auth/register \
    -H "Content-Type: application/json" \
    -d '{"username":"Test_02","email":"test2@mail.com","password":"secret123"}'
  # Puis dans phpMyAdmin : base Launcher -> table users -> Parcourir :
  # tu dois voir Test_02. C'est gagne.

DEPANNAGE
---------
- "Access denied for user 'launcher_api'" : mauvais mot de passe ou
  user cree seulement en 'localhost'. Refais l'etape A.2 avec '%' et
  verifie dans phpMyAdmin -> Comptes utilisateurs.
- "connect ECONNREFUSED" / timeout : bind-address encore en 127.0.0.1
  ou firewall. Revois l'etape B.
- "Unknown database 'Launcher'" : faute de frappe dans DB_NAME
  (respecte majuscules/minuscules).
- "Table 'Launcher.users' doesn't exist" : etape A.1 non faite.
- Revenir au MySQL Docker : DB_HOST=db dans .env puis
  docker compose --profile mysql-docker up -d --build

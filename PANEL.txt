PANEL WEB ADMIN - TUTO
======================
Acces : http://IP_SERVEUR:3001/panel/  (ex : http://89.168.51.174:3001/panel/)
Pas de port a ouvrir en plus : c'est le meme que l'API (3001).
Inscription (page TEMPORAIRE, sera supprimee) : http://IP_SERVEUR:3001/register/

PRINCIPE
--------
- Table separee panel_users (isolee des comptes jeu), creee automatiquement.
- UN SEUL compte possible : celui defini dans le .env. Aucune inscription
  publique, personne d'autre ne peut se creer d'acces.
- Token separe du jeu (12h) : un token jeu ne passe pas sur le panel.
- V1 : login -> message "Vous etes bien connecte" + logout.

INSTALLATION (sur le Linux, en SSH)
-----------------------------------
  cd ~/LauncherMinecraft
  git pull
  nano .env
  # Ajoute / remplis (mot de passe DEDIE au panel, different du jeu) :
  #   PANEL_ADMIN_USER=admin
  #   PANEL_ADMIN_PASSWORD=TonMotDePasseFort_Ici
  docker compose up -d --build
  docker compose logs --tail=20 api
  # Attendu : [DB] Compte panel admin "admin" cree  (ou rien s'il existe deja)
  #           [API] http://localhost:3001 -> /api/health

TEST
----
  1. Ouvre http://IP_SERVEUR:3001/panel/ dans ton navigateur.
  2. Connecte-toi avec PANEL_ADMIN_USER / PANEL_ADMIN_PASSWORD.
  3. Tu dois voir : "Vous etes bien connecte" + ton pseudo.
  4. Bouton "Se deconnecter" -> retour au login.

  Mauvais identifiants -> "Identifiants incorrects." (normal, anti-bruteforce actif).

CHANGER LE MOT DE PASSE PANEL
-----------------------------
  Option simple (recommandee) : change PANEL_ADMIN_PASSWORD dans le .env,
  supprime la ligne en BDD, rebuild (le compte est re-cree) :
    (phpMyAdmin, base Launcher, onglet SQL)
    DELETE FROM panel_users WHERE username = 'admin';
    (puis sur le Linux)
    docker compose up -d --build

DEPANNAGE
---------
- Page blanche / 404 sur /panel/ : verifie le slash final (/panel/) et que
  l'image a bien ete rebuild (docker compose up -d --build apres git pull).
- PAGE QUI NE CHANGE PAS / vieux design / CSS absent : c'est le CACHE du
  navigateur (le serveur a la bonne version, verifie en curl). Solution :
  Chrome/Edge : F12 -> onglet Application -> Stockage -> "Effacer les donnees
  du site", ou Ctrl+Maj+Suppr -> "Images et fichiers en cache" -> Effacer.
  Puis recharge /panel/. Le HTML est en no-store depuis la v4, ca ne reviendra plus.
- /register/ : page d'inscription TEMPORAIRE (comptes jeu via le web).
  Pour la supprimer plus tard : effacer server/src/public/register/ + le bloc
  "/register" dans server/src/index.js, puis rebuild.
- "Identifiants incorrects." alors que c'est les bons : les vars .env etaient
  vides au boot -> regarde les logs : "[DB] PANEL_ADMIN_USER/PASSWORD non
  definis". Corrige le .env puis rebuild (le seed ne tourne qu'au demarrage).
- "Session expiree" : token 12h depasse -> reconnecte-toi.
- Un token du JEU colle dans le panel -> refuse ("Token invalide pour le panel").
- Voir les comptes panel (phpMyAdmin) :
    SELECT id, username, created_at FROM panel_users;
